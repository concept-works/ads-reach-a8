# ADS-REACH-A8 v0.5.1

- Windows: `build-windows.bat` をダブルクリックし、dist内のポータブルEXEを配布。
- macOS: GitHub ActionsからUniversal DMGをビルド。
- ログインはChrome/Edgeで手動。データ取得は一覧API (pageSize=100)、詳細HTML HTTP取得。
- STEP 1（一覧）とSTEP 2（NGワード）の進捗バーを分離。
- 詳細URLへのアクセス間隔: 3秒→1秒（一覧APIは3秒を維持、エラー時の再試行待機も維持）。
- ログアウト時は非表示リンクをクリックせず、既存の `logoutFormHeader` フォームを送信します。ページ遷移が確認できない場合はログに警告を記録し、ブラウザを閉じます。
- **注意**: フォーム送信・ページ遷移の確認はサーバー側のログアウト成功の完全な証明ではありません。ログイン状態が失効するか実機テストが必要です。
- **注意**: 詳細1秒間隔はA8.netの許可されたレートを意味しません。利用条件とアクセス制限を遵守してください。
- HTTP 429/403などの場合は既存の停止挙動を維持します。
- チェックポイントからの自動再開は未実装です。
